## Project Description 
Travel Destination Advisor is a Flask-based web app that helps users find travel destinations tailored to their preferences. It uses data from TripAdvisor and RapidAPI, combined with a custom scoring system that matches destinations to user inputs like budget, weather, duration, and month.
   
## Objective
Suggest locations based on weather, budget, and interests

## Possible Computational Techniques
1. Multi-criteria scoring
2. Simple filtering
